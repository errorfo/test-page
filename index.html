API Protocol: connection_sync (v1.0)

The connection_sync protocol is used to initialize the handshake between the client and the validation node.

Required Parameters:

  • action: Set to connection_sync_init
  • auth_token: The user's unique identifier (e.g., the current session ID).
  • endpoint_url: The target validation node URL.

Implementation Note: To perform a successful handshake, the auth_token must be appended as a query parameter to the endpoint_url. For example:
endpoint_url?action=connection_sync_init&auth_token=[USER_ID]
